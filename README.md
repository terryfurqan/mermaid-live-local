# Mermaid Live — Local Editor

Standalone local HTML replica of **Mermaid Live Editor** (`mermaid.live`) with:
- Split-pane resizable Code & Config JSON editor with line numbers and live error reporting
- `redux-dark-color` and all Mermaid v11 themes
- Load `.mmd` (`Cmd/Ctrl + O` or Drag & Drop) and Save `.mmd` (`Cmd/Ctrl + S`)
- Export to **SVG** and **PNG**
- Pistol-style **Safety Lock** (`🔒`) guarding the external `mermaid.live` button to prevent accidental data sharing
